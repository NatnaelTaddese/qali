## What's new in 0.1.4

- **Multi-day events in the month view.** All-day events that cover several days are now one bar across their days, like in the week view, instead of a chip repeated in every cell. An event that runs past the end of a week carries on from the start of the next row, squared off where it continues. Busy days still show "+N more".
- **Change how a series repeats.** When you organise a repeating event, you can now change its repeat from the edit form. Save it for this and following events, or for all events. Choosing "Does not repeat" ends the series before the event you're editing.
- **Updates in the toolbar.** New versions now show as a pill in the toolbar, next to the Day/Week/Month switch, instead of in a separate window. From there you can update, watch the download and relaunch. Settings → General → Updates shows the same status.
- **Sharper grid edges.** The time rail and the header now end in a subtle native macOS separator line. The rail's edge stays put while you swipe between days.
